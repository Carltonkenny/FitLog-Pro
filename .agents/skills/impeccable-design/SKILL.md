# Impeccable Design Standards

## 1. Zero Visual Noise
- Remove arbitrary decorative elements that don't convey information.
- Clean hierarchy: Title, primary stat, clear delta/status indicator.
- Contrast ratios meeting AA/AAA without blinding neon overlays.

## 2. Plain English Clarity
- Demote Latin/hectic academic jargon.
- "Muscle Growth" instead of confusing terms.
- "Growth vs. Fatigue Score" instead of raw acronyms like "SFR".
- "Estimated Max Lift" instead of cryptic "Epley 1RM".

## 3. Tactile Feedback
- Clear active states, sound beeps for interval completion, smooth toggle pills.
- Real-time updates with smooth CSS transitions.
