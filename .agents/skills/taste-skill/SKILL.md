# Taste Guidelines: Avoiding Generic AI Aesthetics

## 1. Reference Elite Tier Products
- **Linear**: Deep black slate surfaces, razor-sharp 1px dividers, command palettes, keyboard-first velocity.
- **Apple Fitness+**: Clean, bold typography, vibrant emerald/amber rings, tabular timer digits, large thumb-friendly touch targets.
- **Raycast**: Monospaced metadata badges, crisp iconography, instantaneous feedback.
- **Supabase / Stripe**: High typographic rhythm, clean graphs, zero clutter.

## 2. Anti-Patterns (What Makes AI Apps Look Cheap)
- ❌ Centering everything in a floating phone mockup on a 1440px desktop display.
- ❌ Gradient text on every single heading.
- ❌ Displaying raw database IDs, hash codes, or tech stack names like "fczhckzsynzfomytkgym" in consumer screens.
- ❌ Hectic academic medical jargon that confuses everyday gym goers.
- ❌ Purple-indigo gradient mush with oversized dropshadows.

## 3. Laptop vs Mobile Mastery
- **Desktop / Laptop (>=1024px)**: Expand into a 3-column Master-Detail studio with rich visualizations, persistent navigation, and live telemetry.
- **Mobile (<1024px)**: Single column with dedicated bottom thumb navigation and expandable sheets.
